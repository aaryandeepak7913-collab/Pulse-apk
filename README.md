# Pulse

A minimal Bluetooth TV remote for Android. Pair your phone with a TV, then use it as a remote, touchpad and keyboard over Bluetooth HID — nothing to install on the TV.

Built with Kotlin, Jetpack Compose and Material 3.

## Build

Every push to `main` builds an APK with GitHub Actions (see `.github/workflows/build.yml`). Download it from the **Releases** page or from the run's artifacts.
